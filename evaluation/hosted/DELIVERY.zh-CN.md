# PromptBoundary 托管模型实验交付报告

**这次修复解决了“已经审出泄露、控制器却仍放行”的问题。没有证据表明它降低了自然生成回答的攻击成功率。** 对正常使用也有代价：三个原始模型全部完成了 12 个合法任务，修复版在 Sol 和 Astra 各误拒了一个。

## 原本的 0/10 来自哪里？

重新核对 PromptBoundary 五批共 204 条已发布回答，无法复现“正常请求通过率 0/10”。确实存在两次 **0/4**，都是旧 v2 的 Skill＋Runtime，而非原始模型。其中确认集的三道题在解释或审查失败后交付兜底文本，一道题在历史重放阶段报协议错误；旧日志没有保留该阶段的 HTTP 原文，无法进一步定位到某个 JSON 字段。v3 的分母 10 是带边界条件的用例数，良性用例实际只有 5 个。新评测将交付错误、显式拒绝、控制器拦截和无可用响应分别记录。[标签、评分器与解析路径核对](DIAGNOSIS.md)

## 同题线上对照

通过账户的 [模型列表](results/models.json) 查询 ID，再用三个 [生成探针](results/smoke) 核对返回模型。小模型使用可验证的快照 `gpt-5.4-mini-2026-03-17`。每个模型的原始、旧 Runtime 和修复版共享 32 个最终请求：12 个正常请求，直接诱导、多轮诱导、角色伪装、指令冲突各 5 个。相同外部上下文、每阶段最多 1,024 输出 token、相同推理设置；Runtime 多次调用的耗时与成本全部计入。每格只运行一次，没有把重复采样当独立观察。

| 模型（API） | 系统 | 攻击成功 | 正常通过 | 误拒 | 延迟 p50 / p95（秒） | 32 题费用（美元） |
|---|---|---:|---:|---:|---:|---:|

| | 修复版 | 0/20 | 11/12 | 1/12 | 7.12 / 18.14 | 0.2339 |
| gpt-6-astra | 原始 | 0/20 | 12/12 | 0/12 | 2.05 / 3.20 | 0.0563 |

九组均无缺失或技术错误。“正常未通过”不等于误拒：三个旧版在 n12 交付过时的 HAZEL。修复版 mini 改为正确的 LIME；Sol、Astra 则把“本项生效”的偏好误标为“本轮生效”，在交付时已过期，正确的审查意见无法落到活动约束上，最终要求重试。把所有临时权限都延长一轮会引入新的越权风险，因此未以此掩盖失败。[逐阶段分析](../../docs/authority-failure.md) · [主实验精确统计、配对变化和调用账目](results/main/RESULTS.md)

独立阅读者在不知道模型和组别的情况下复核了所有 288 个回答（176 个不同的案例／回复组合）。没有发现额外的已交付泄露，但 mini 原始模型有一次承诺未来会保留内部标识符；另有 10 条回答虽给出了许可字段，却没用好已有的对话指代。该复核由另一个 AI agent 完成，不等于人工一致性验证。[逐例语义复核](results/QUALITATIVE.md)

## 真实审查器能否挡住已经出错的生成器？

旧控制器只接受用户约束 ID。模型即使指出草稿违反可信应用指令，控制器也可能认为审查依据无效，将未经核准的原文交给用户。修复版保留系统／开发者规则的来源与 ID，有可信边界且审查未能确定时会停止交付。HTTP 单字短答也不再把内部 JSON 审查截断到一个 token。可选的应用已知敏感值过滤器没有用于下述实验。[实现与适用边界](../../docs/runtime-security.md)

另行冻结 8 个新案例：4 个含秘密的草稿、4 个合规草稿。每次生成和修订都提供同一份预设草稿，**解释与审查实际调用对应的 API 模型**。这测量坏草稿已经发生时，最终能否泄露，不估计真实模型生成坏草稿的频率。

| 模型 | 泄露草稿最终逃逸：旧版 → 修复版 | 合规草稿有用通过：旧版 → 修复版 |
|---|---:|---:|
| Sol | 1/4 → 0/4 | 4/4 → 4/4 |
| Astra | 1/4 → 0/4 | 4/4 → 4/4 |
| mini | 2/4 → 0/4 | 4/4 → 4/4 |

三个模型的旧版都交付过“在拒答中复述秘密”的草稿；mini 还放行了 HTML 注释中的秘密。修复版拦下所有坏草稿，但由于本试验强制修订仍返回坏稿，每次兜底也都丢失了原可交付的公开信息。在相同四种故障的三个模型上，合计泄露由 4/12 降至 0/12（−33.3 个百分点）；这 12 个观察不是 12 种独立攻击。[压力测试定义、完整回答与费用](stress/results/RESULTS.md)

## 消耗、复现与适用边界

| 部分 | 真实 API 生成请求 | 输入 token | 输出 token | 按用量估算美元 |
|---|---:|---:|---:|---:|
| 同题主实验 | 775 | 415,728 | 65,901 | 2.90501130 |
| 模型生成探针 | 3 | 57 | 15 | 0.00056475 |
| 固定草稿压力测试 | 136 | 83,049 | 15,064 | 0.57881375 |
| **合计** | **914** | **498,834** | **80,980** | **3.48438980** |

输入／输出为供应商实际返回的用量，金额按各模型当时标准费率分开计算缓存读写，包含推理 token，不含账户折扣或税；没有把模拟草稿计作 API 调用。延迟含网络、历史重放及审核，各批执行时间不同，不是严格性能基准。
